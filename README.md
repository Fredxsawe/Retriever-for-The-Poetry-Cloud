# Retriever-for-The-Poetry-Cloud
真实可用的诗云检索器

在《诗云》这部小说中，外星文明为了找出最好的诗，以穷举的方式演算出所有文字可能的排列组合，并存储起来，形成一个巨大的数据库“诗云”。

虽然由于排列组合种类过多，人类目前还无法在事实上存储所有的诗，但假如存在一个以固定规则排列的“诗云”的话，我们可以通过直接计算的方式获取一首诗在“诗云”中的编号，或根据编号生成一首诗。

这个简单的算法目前只能计算所有五言绝句或七言绝句的相关编号，支持所有的unicode汉字（截至2026.8.22），共有约1.749*10^140种可能。
